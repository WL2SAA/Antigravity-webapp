# Legal Disclaimer & Fair Use Notice

## 1. Purpose of This Repository
This repository is an offline technical archive, reverse-engineering study, and architectural documentation of the public frontend web application originally served at `https://antigravity.google`.

This project was assembled strictly for **educational, non-commercial research, and design study purposes**, including:
- Analyzing modern multi-page Astro v7 + Starlight architecture.
- Studying high-performance WebGL GPGPU shader math, Poisson Disk Sampling particle simulations, and Three.js physics.
- Documenting advanced GSAP animation pipelines, custom cursor followers, and responsive typography layouts.
- Developing robust zero-dependency offline local preview tooling (`serve.py`).
